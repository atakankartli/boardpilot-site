Board Pilot support

Connect to your server

Open Settings in the app. Enter the address of your Board Pilot server and its token, then tap Test connection. The server prints the token when you install it.

Try it without a server

Tap "Try the demo" on the first screen, or turn on Demo mode in Settings. The demo uses built-in sample data.
